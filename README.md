# Nyota Swerve

A premium, responsive website for Nyota Swerve Closet — a bespoke tailoring house in Ruiru, Kenya.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

## Features

- Responsive black, charcoal, ivory and gold art direction
- Bespoke services, wedding atelier and process sections
- Filterable portfolio gallery with lightbox
- Appointment and quotation forms that prefill WhatsApp
- Testimonials and style journal content
- Contact details, social links and Google Maps embed
- Mobile navigation, reduced-motion support and semantic controls

## Stack

React, Vite, Lucide icons and custom CSS.
